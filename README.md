# Codera
 
Gamified coding practice platform — daily streaks, quests, loot chests, and weekly boss battles to make learning to code addictive.
 
## Concept
 
Codera combines the daily-habit mechanics of Duolingo with LeetCode-style coding challenges and RPG progression:
 
- **Daily streaks** — keep your streak alive by solving problems every day
- **Quests** — structured learning paths through programming topics
- **Loot chests & sprites** — earn chests for completed quests, unlock sprites with gameplay buffs
- **Weekly boss battles** — timed community challenges where your collected buffs matter
- **NPC challenges** — meet characters along the quest path who assign LeetCode-style problems for coins and XP
## Roles
 
- **Player** — completes quests, solves problems, collects sprites, competes in boss battles
- **Content creator** — builds new quests, problems, and NPC storylines
- **Administrator** — manages users, moderates content, oversees the in-app economy
## Tech stack
 
- **Backend:** Python (Flask)
- **Database:** SQLite (dev) → PostgreSQL (production)
- **Frontend:** HTML, CSS, vanilla JavaScript
- **Code execution/testing:** sandboxed evaluation of submitted solutions (TBD)
